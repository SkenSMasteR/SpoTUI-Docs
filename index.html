Installation

        

          

            
Linux

            

              
curl -fsSL -o install.sh https://raw.githubusercontent.com/SkenSMasteR/SpoTUI/master/scripts/install/linux/install.sh && chmod +x install.sh && ./install.sh

            

          

          

            
Windows

            

              
iwr -useb https://raw.githubusercontent.com/SkenSMasteR/SpoTUI/refs/heads/master/scripts/install/windows/install.ps1 | iex

            

          

        

        
Or search for SpoTUI in the Spicetify Marketplace.

      

    


    

      

        
Commands

        

          
            
tui -l -a <on/off>Toggle ASCII animation

            
tui -wp <url> [-o <opacity>]Set wallpaper (opacity 0-1)

            
tui -t pull <theme_id>Apply a theme by its ID (you can find the id on our website)

            
tui -wp offRemove wallpaper

            
playlist / listOpen playlist viewer

            
play / pause / pToggle playback

            
skipNext track

            
s / seek <mm:ss>Jump to a specific time

            
v / volume <%>Set volume (0-100)

            
shuffleToggle shuffle

            
loop / superloopToggle repeat mode

            
lyricsToggle lyrics panel

            
searchOpen Spotify's native search

            
themeBrowse and apply themes

            
helpShow the help panel
